# Our Household

A simple, beautiful shared household app for managing home life together.

## Features

- **Home**: Today's overview
- **Plans**: Monthly calendar for plans
- **Grocery**: Shopping list + meal planning
- **Bills**: Bills calendar and tracking
- **Chores**: Shared chore list
- **Notes**: Quick notes for each other

Data is stored in `data.json` in this repository via the GitHub API, so both of you always see the latest.

## Setup

1. This site is designed for GitHub Pages. Go to repo Settings > Pages > Source: Deploy from branch `main` / root. Your site will be at `https://RabbitZ0.github.io/our-household/`
2. Create a Personal Access Token (classic) with `repo` scope at https://github.com/settings/tokens
3. On first visit, enter your GitHub username, the repo name (`our-household`), and the token. It's stored only in your browser.
4. Add your wife as a collaborator if needed so she can also write (or share the token carefully).

## PWA

You can install it to your phone home screen from the browser menu ("Add to Home Screen" / "Install app").

Enjoy your organized home! 🏡
